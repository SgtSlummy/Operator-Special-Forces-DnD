# Campaign engine redesign: companion and authority audit

Status: active implementation, not a release certificate. September 6, 2026.

The user's objective is to reassess and redesign the engine for the persistent, choice-driven campaign. Discord must support required play and information; the browser is an optional companion. The governing scope includes `RAPH_TACTICAL_IMPLEMENTATION_PLAN.md`, `PERSISTENT_WORLD_PLAN.md`, the image/style requests and later player-information requirements. Passing the checks below does not establish completion of the whole objective.

## Architecture decision and concrete correction

`app/page.tsx` previously created its own `Campaign`, deterministic omen, mission consequences, readiness, factions, relationships and world-day progression in localStorage. That state could disagree with the authenticated tactical/world ledger while the UI called itself a shared persistent world. The root now composes the existing `Play` component; `/` and `/play` query and command the same authenticated services. No localStorage prototype outcome, invented die result, reset or time-advance control remains in the root implementation. Existing browser storage is not deleted or silently imported as authoritative world history.

Standalone image-only campaigns retain their original `SceneImages` flow at `/illustrations`, linked from the new home page. Tactical images continue to use the game session. This is an entry-point migration, not a migration of old prototype history into the game database. Importing any old fictional history would need explicit host review and a validated event migration.

The intended boundary is: authenticated player scope -> authorized queries or revision-bound commands -> shared game/world ledger -> projections for Discord, browser, precise maps and scene illustrations. Presentation modules do not decide damage, consequences, visibility or branch outcomes. Image generation and narration do not establish mechanics. Imported sheet values are reviewed source snapshots; current encounter resources belong to the game ledger.
