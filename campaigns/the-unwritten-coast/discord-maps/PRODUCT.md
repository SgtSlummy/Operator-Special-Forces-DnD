# The Unwritten Coast map table

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated by the user's instruction to continue building at discretion. A standalone local HTML/CSS/JavaScript viewer keeps this work separate from the live game and Unity migration.

## Users and purpose

The campaign's GM and players need detailed 3D maps with individual architectural layers and matching player markers. The user explicitly requested Discord play and supplied the VIBEZ #dnd-arcade channel. This local table is a GM preparation and manual position tool; exported current-view images can be shared in Discord.

## Capabilities and constraints

Start with Beacon Heart and the ferry landing. A token has one shared area, layer and normalized position. Both overview and slice render that record. All starting tokens are illustrative previews; actual names and positions are undecided. No live Discord tracking or automatic adjudication is claimed. The user determines character actions. Preserve other campaigns, the live game, cloud configuration and Unity project. Keep all files outside OneDrive.

## Brand commitments

The Unwritten Coast; detailed painted stone-and-brass architectural cutaways, water, layered dungeon spaces, and room-to-region maps based on the user's reference collection. Original generated artwork is already available in campaign-art/unwritten-coast/v1.

## Evidence on hand

Campaign README, validated portable dungeon export, seven original map images. Beacon Heart's canonical envelope is 180 feet diameter and 300 feet high. Individual floor elevations and floor contents here are proposed additions. Ferry below-deck geometry is proposed. Maps are illustrations, not surveyed collision geometry.

## Product principles

- The maps lead; controls stay clear and compact.
- A player position has one source for both views.
- Separate scene discovery from GM preparation.
- Show manual and preview status honestly.
