# Local generated assets

These files were generated locally with the installed AUTOMATIC1111 server and
are kept separate from the reviewed Witnesslight library manifest.

- `on-discovery/camp-emberfall-overhead-sd-v002.png` is the accepted overhead
  tactical-style draft for the Camp Emberfall presentation layer.
- `on-discovery/camp-emberfall-overhead-sd-v002.provenance.json` records the
  prompt, negative prompt, checkpoint, sampler, seed, and generation time.

The first and third attempts are retained as diagnostics. They are not approved
scene art. None of these images define movement, visibility, collision, or
combat state; those facts come from RPG-Core.
